# 分发形态从绿色单文件改为 NSIS 安装包

Tauri 不擅长单文件自解压。我们接受 NSIS 安装包作为主分发形态，换来体积从约 13 MB 降到约 4–8 MB。**代价是失去「下载 exe 双击就跑」的绿色体验**，用户必须先安装。

## Status

proposed

## Considered Options

- **NSIS / MSI 安装包（选定）**：Tauri 默认产物，体积小，卸载与开始菜单条目由安装器管。
- **仍做单文件 exe**：需把 WebView2 bootstrapper 带走并在首次运行时自解压到临时目录，实践中自解压、杀软误报、临时目录清理三处都容易翻车，且和 Tauri 的产物结构对着干。
- **两者都出（安装包 + 免安装 zip 目录版）**：覆盖两种偏好，但每发布要验两套产物。等真有用户抱怨再补。

## Consequences

- 面向的是运维场景：服务机上未必愿意跑安装器。发布说明要明确给出安装步骤。
- 安装后升级路径是覆盖安装，`settings.json` / `presets.json` 的位置需放在用户目录（而非安装目录），否则覆盖安装会清掉用户的预设与偏好。当前版本这些文件在程序侧路径，迁移时要一并改。
- 自我更新暂不做（见无自更新决定）：用户手动下载新安装包覆盖安装。
