肉眼可见的差异点

维度现状NaiveUI 默认
圆角卡片 12px / 控件 8px，明显圆润统一 3px，方正、企业后台观感
主色#0a84ff 蓝（Apple 系统蓝）#18a058 绿 / 深色下 #63e2b7 薄荷绿
字阶六级严格递减 18/15/13/13/12/11，有 test_font_tokens.py 守护库内默认 16/14/14/14/13/12，层级压缩（section=group=body=14）
字体微软雅黑 UI + Cascadia Mono（数值/日志）v-sans（system-ui 栈）+ v-mono
滑块6px 轨道 + 16px 圆柄（CTkSlider）4px 轨道 + 14px 柄，更细
卡片分隔浅灰底 + 1px 描边 + 极淡投影同构，但圆角与色温不同，整体更「扁平」
状态圆点#30d158 绿 + 呼吸动效（30s 无交互静止）默认无动效，需自行实现
「?」提示框300ms 触发 / 200ms 淡入 / 0.8s 指数渐隐（motion.py 手写）n-popover，默认瞬时显隐，渐隐曲线需自配

注：右面板是默认主题。NaiveUI 支持全局主题覆盖（primary color / borderRadius / 字号）， 要逼近左面板需自写 themeOverrides —— 那时「用 NaiveUI 省事」的收益会打折，但「省掉自绘组件」的收益仍在。
