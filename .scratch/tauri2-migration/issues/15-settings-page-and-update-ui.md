# 15: 设置页与官方更新 UI

**What to build:** 设置页：界面语言、外观、动效开关，以及官方更新区（当前版本、构建线选择、立即检查、立即更新、更新日志、进度输出）。用户视角：所有偏好与官方更新的操作集中在一处完成。

**Blocked by:** 12, 10

**Status:** ready-for-agent

- [ ] 界面语言中英切换（参数详解保持中文）
- [ ] 外观：跟随系统 / 浅色 / 深色
- [ ] 动效总开关；关闭后所有动画直跳终态，功能不缺失
- [ ] 官方更新区显示当前已安装版本，读不到时显示「未知」
- [ ] 构建线可选：cuda-13.4 / cuda-12.4 / cpu / vulkan
- [ ] 启动时自动检查更新，但只提示不安装
- [ ] 发现新版本时展示更新日志，由用户决定是否更新
- [ ] 立即更新前二次确认，并展示备份目录
- [ ] 更新全过程日志实时滚动输出
- [ ] 组件测试覆盖：设置项变更、更新确认流程、进度展示
