# 13: 参数表单控件与「?」解释提示

**What to build:** 主窗体的参数区：7 个可折叠分组，数值用滑块、枚举用下拉、布尔用复选、文件路径用输入框加浏览按钮，每个参数右侧有「?」按钮给出中文解释。用户视角：不用手敲命令行参数，且每个参数都能立刻知道它对性能/效果的影响和适用场景。

**Blocked by:** 12

**Status:** ready-for-agent

- [ ] 7 个分组可折叠，默认展开前两组；展开状态在切换语言/主题后保留
- [ ] 数值字段用滑块 + 实时数值读数（GPU 层数、上下文长度、并发槽、批大小、温度、min-p、线程）
- [ ] 枚举字段用下拉（投机解码、KV cache 类型、Flash Attention、监听地址）
- [ ] 布尔字段用复选框（禁用 mmap、锁定内存、禁用 KV 卸载、MoE 走 CPU）
- [ ] 文件路径字段用输入框 + 浏览按钮（模型文件、视觉投影）
- [ ] 每个参数有「?」按钮，显示该参数对性能/效果的影响与适用场景（中文）
- [ ] 下拉切换选项时显示当前选项的解释
- [ ] 数值读数用等宽字体且与正文同行高（避免行盒错位）
- [ ] 组件测试覆盖：控件渲染、值变更、分组折叠状态保持
