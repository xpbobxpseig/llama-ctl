# 09: 早期 tracer bullet — 读完一个服务状态并渲染出状态卡

**What to build:** 打通第一条端到端路径：Rust 侧读取一个 Service 的 Fact，经由 IPC 送到 Vue 前端，前端渲染出一张状态卡（服务名、运行状态、健康探测结果、安装目录）。只做这一屏，不做表单、不做控制按钮。

这是在领域层全部完成之前就验证 IPC 与渲染是否跑得通。价值在于提前暴露 WebView2 / Tauri 配置 / CSP 这类环境问题——它们与领域逻辑无关，拖到最后发现代价最大。

**Blocked by:** 01, 04

**Status:** ready-for-agent

- [ ] 一个 tauri command 返回单个服务的 Fact 快照，前端能取到
- [ ] 前端渲染出状态卡：服务名、运行状态、健康探测、安装目录
- [ ] 窗口能正常打开，样式生效（证明前端资源随包分发可用，ADR-0001）
- [ ] 无控制台报错；CSP 已配置且不阻断本地资源
- [ ] 服务不存在 / 服务停止等异常状态能正确显示，不白屏
- [ ] 这一屏的渲染有组件测试（mock IPC），后续前端票都以此为样板
