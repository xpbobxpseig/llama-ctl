# 03: params — AppParameters 解析、重建与语义等价

**What to build:** 把参数层移植到 Rust：把 `AppParameters` 文本解析为 Field 值、从 Field 值重建回文本、以及两者的语义等价判定。用户视角：历史遗留配置、手写配置、其他工具生成的配置都能被正确识别，不会因为是短名写法或参数顺序不同就被误报成「未应用更改」；而真正的数值改动一定被检出。

这是整个工具正确性的地基，也是唯一一个零外部依赖的领域模块（现有实现只 import `math`），可以最先落地。
